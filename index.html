Designer
  • Add a state: double-click on the canvas
  • Make accept state: double-click on an existing state
  • Add an arrow: shift-drag on the canvas
    Either from state to state or, to create the start state, from canvas to state
  • Move something: drag it around
  • Delete something: click it and press the delete key or shift + backspace
  • Multi select: ctrl + select a region
Text Editing
  • New line: press Enter or type \n
  • Subscripts: q_1, q_13, q_a, ...
  • Greek letters: \alpha, \beta, \gamma, ... — @e is a shortcut for epsilon (ε)
  • \es for ∅
  • cup for ⋃
  • -> for →
  • \ecell or @c for ∆
  • \dashv or @t for ⊣
  • \estack or @s for ⟂
DFA
  • Each link label is a comma-separated list of input symbols:
    a — transition on a
    a,b — transition on a or b
PDA
  • One rule per line (press Enter for a new line), format: input,stack / op
    a,X / push XY — if input=a, top=X, push X then Y
    a,X / pop — if input=a, top=X, then pop
    a,X / @e — if inputa, top=X, then leave stack unchanged
    Use @s is empty stack ⟂.
TM
  • Each link label is one or more transitions separated by two spaces, format: read/write dir
    a/b R — read a, write b, move right
    @c/$ R — read blank cell, write $, move right
    @t/@t R — read left-end marker, keep it, move right
